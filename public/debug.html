      Why not

      Ask the engine about an action the table did not offer. The host applies it to a copy of the live state and shows the engine's refusal with its CR citations, or what would change if the engine takes it. The live match, its log, and the seat pages are not touched. An engine intent names no seat: the engine acts for whoever the state says, and the seat picked here is checked against the list the table offers that seat.

      The JSON is sent as it is. Edit it for fields the pickers do not fill, such as an ability id or a subroutine index.

      Export as an engine test

      Downloads this match as a fixture for the engine's tests: the opening state, every engine action applied (including empty windows the host passed), the invariant failures by step, and the final state. Copy it to netrunner-engine/tests/fixtures/game-exports/ to keep it as a regression test.

      Start from a position

      Starts a new scenario match from this JSON. Card ids are the cards data ids at the cards pin. Ice on a server is listed outermost first (the order a run approaches it); decks are top card first. start: "turn" begins that turn (clicks, recurring credits, the Corp's draw); start: "action" begins the action phase with the listed clicks. Placed cards were not installed, rezzed, or scored, so nothing that triggers on those fires.

      Golden transcript

      Step the engine's frozen runs one intent at a time. This is a separate demo game, not the live match.
